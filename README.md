# ScaledPapers blog

These posts are a public copy of the validated articles on https://scaledpapers.com/blog. The site is published from the product repository. This tree is rewritten when that repository's master branch updates.

To propose an edit, open a pull request on a post. Approving it opens a pull request on the product repository. Merging that pull request publishes the change, and this repository is then rewritten to match.
