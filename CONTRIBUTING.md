# Contributing

These posts are a public copy of the validated articles on https://scaledpapers.com/blog.

Open a pull request that edits the post. Approving it opens a pull request on the product repository. Merging that pull request publishes the change. This repository is then rewritten to match, so a pull request merged only here does not stay.

Fix wording, commands, and mistakes in the post. Product behavior stays in the ScaledPapers docs.
